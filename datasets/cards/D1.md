# D1 HRCA

Primary source: https://zenodo.org/records/4539695 ; API evidence in ../evidence/D1_metadata.json. CC BY 4.0, open. 248 dysphagic participants / 3,144 swallows. 4-kHz microphone + three accelerometer channels; synchronized VFSS onset/offset frames at 60 fps. Signals archive 1,406,291,807 bytes, labels archive 301,884 bytes. Neither waveform schema nor file-to-participant map has been inspected. Frame zero/one indexing must be determined, not assumed. No clinical PAS labels verified. Source population is not a healthy/diseased classification endpoint. `hrca.py` accepts explicitly verified arrays; storage parser remains blocked. Approval required for large signal download.
