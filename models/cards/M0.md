# M0 model card

Endpoint: swallow event versus explicitly defined non-swallow event classes. Intended users: laboratory researchers. No disease/aspiration/clinical risk endpoint.

Candidate baselines: standardized logistic regression and bounded random forest; candidate CNN: temporal convolutions represented as Conv2D(width=1). Actual training/export/evaluation status and source are in reports/MILESTONE_01.md and any real-data report. No synthetic result establishes performance.

Grouping unit: participant, including repeat sessions. Default deterministic split 70/15/15 with rounded subject counts. Training-only normalization and representative calibration. Validation selects candidates; test subjects are held out. Report window confusion/precision/recall/F1 and subject-cluster CI; continuous timing and false events/min require annotated long recordings.

Known limitations: small datasets, protocol/task cues, publisher QC selection, age/population mismatch, source microphone versus PVDF domain shift, missing optical/respiratory signals, unmeasured hardware performance, no external clinical validation. A non-swallow class of cough/throat-clear does not represent every daily activity.

Artifact weights are not included merely as placeholders. Clinical risk, safety clearance and treatment recommendation are disabled in the current output contract.

Executed D4 v2 pilot: validation-selected random forest, test F1 0.9085 on six held-out healthy participants. The CNN candidate exports to 5,736-byte INT8 but has a documented saturation-associated parity outlier and is not selected for deployment. See reports/M0_D4_RESULTS.json and QUANTIZATION_FAILURE_ANALYSIS.json. Actual weights are delivered separately from the source repository. These are exploratory event-clip results.

Milestone 02: three fixed-CNN calibration variants and three exact linear-feature INT8 comparators all failed the frozen validation parity criteria. None is eligible for deployment. A 26-participant development-only grouped CV study found paired logistic F1 0.9367, with overlapping uncertainty intervals across modalities/models; this does not replace the M01 reference or establish external/clinical performance. See reports/MILESTONE_02.md for all attempts and abstention denominators.
