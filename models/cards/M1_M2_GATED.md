# Gated future stages

M1 is an untrained candidate architecture with the PDF's optical/PVDF/EMG/respiratory inputs, eight timing features and an event head. Public channels cannot fill absent prototype modalities. It requires synchronized measurements from the real device and optical-ablation experiments on the same participants. Parameter count alone is not memory or latency evidence.

M2 is not implemented and cannot be enabled by a configuration flag. Clinically adjudicated labels, appropriate reference assessments, ethics/safety review and endpoint-specific validation are prerequisites. No M0/M1 event result is a dysphagia, aspiration, swallowing safety or treatment decision.
